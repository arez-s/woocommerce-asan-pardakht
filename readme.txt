درگاه REST آسان پرداخت پرشین (آپ) برای ووکامرس.

== امکانات ==

* دریافت Token و انتقال POST به درگاه شاپرک
* دریافت نتیجه، Verify و Settlement تراکنش
* پشتیبانی از فروشگاه‌های ریالی و تومانی
* سازگار با HPOS ووکامرس
* قابل استفاده در تسویه‌حساب کلاسیک و Checkout Block ووکامرس
* گزارش اشکال‌زدایی اختیاری بدون ثبت رمز API
* کنترل کلید سفارش و شماره فاکتور در Callback

== نصب ==

1. فایل ZIP افزونه را از بخش «افزونه‌ها > افزودن افزونه تازه > بارگذاری افزونه» نصب و فعال کنید.
2. به «ووکامرس > پیکربندی > پرداخت‌ها» بروید.
3. درگاه «آسان پرداخت (آپ)» را باز کنید.
4. نام کاربری API، رمز عبور API و Merchant Configuration ID را وارد کنید.
5. واحد مبلغ فروشگاه را بررسی و درگاه را فعال کنید.
6. نشانی Callback نمایش‌داده‌شده در تنظیمات را، در صورت نیاز، به شرکت پرداخت اعلام کنید.

API مبلغ را به ریال دریافت می‌کند. اگر قیمت‌های فروشگاه به تومان هستند، گزینه تومان را انتخاب کنید. حالت خودکار ارزهای IRT، TMN و TOMAN را تومان در نظر می‌گیرد.

== روند پرداخت ==

افزونه مطابق نمونه REST ارائه‌شده، ابتدا Token می‌گیرد. پس از بازگشت مشتری، نتیجه تراکنش را با TranResult دریافت می‌کند، سپس Verify و Settlement را اجرا می‌کند. سفارش فقط پس از موفقیت هر سه مرحله پرداخت‌شده می‌شود. در صورت موفقیت Verify و نامشخص بودن Settlement، سفارش برای جلوگیری از ثبت اشتباه در وضعیت «در انتظار بررسی» قرار می‌گیرد.

== نکات سرور ==

* ارتباط خروجی HTTPS به ipgrest.asanpardakht.ir و asan.shaparak.ir باید باز باشد.
* گواهی SSL سایت و پیوندهای یکتای وردپرس باید درست کار کنند.
* حداقل مبلغ طبق نمونه مرجع ۱۲٬۰۰۰ ریال در نظر گرفته شده است.
