# درگاه آسان پرداخت (آپ) برای ووکامرس

افزونه درگاه پرداخت اینترنتی آسان پرداخت پرشین (آپ) برای ووکامرس، مبتنی بر REST API.

## امکانات

- دریافت Token و انتقال امن مشتری به درگاه شاپرک
- اجرای چرخه کامل `TranResult → Verify → Settlement`
- پشتیبانی از فروشگاه‌های ریالی و تومانی
- سازگاری با HPOS ووکامرس
- پشتیبانی از تسویه‌حساب کلاسیک و Checkout Block
- اعتبارسنجی کلید سفارش و شماره فاکتور در Callback
- ثبت گزارش اشکال‌زدایی اختیاری بدون ذخیره رمز API در لاگ

## نیازمندی‌ها

- وردپرس ۵.۸ یا جدیدتر
- PHP 7.4 یا جدیدتر
- ووکامرس ۵.۰ یا جدیدتر
- گواهی SSL معتبر
- دسترسی خروجی HTTPS به دامنه‌های آسان پرداخت و شاپرک

## نصب

1. فایل ZIP آخرین نسخه را از بخش Releases دریافت کنید.
2. در وردپرس به «افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه» بروید.
3. فایل ZIP را نصب و فعال کنید.
4. از «ووکامرس ← پیکربندی ← پرداخت‌ها»، درگاه «آسان پرداخت (آپ)» را باز کنید.
5. نام کاربری API، رمز عبور API و `Merchant Configuration ID` را وارد کنید.
6. واحد مبلغ فروشگاه را بررسی و درگاه را فعال کنید.

## تنظیم مبلغ

API آسان پرداخت مبلغ را به ریال دریافت می‌کند. در حالت تشخیص خودکار، ارزهای `IRT`، `TMN` و `TOMAN` تومان در نظر گرفته شده و مبلغ در ۱۰ ضرب می‌شود. برای فروشگاه‌هایی با تنظیمات سفارشی، واحد را صریحاً روی ریال یا تومان قرار دهید.

## روند پرداخت

افزونه ابتدا از مسیر `v1/Token` توکن پرداخت می‌گیرد و مشتری را با درخواست POST به `https://asan.shaparak.ir` منتقل می‌کند. پس از بازگشت مشتری، نتیجه تراکنش دریافت و سپس Verify و Settlement اجرا می‌شود. سفارش فقط پس از موفقیت کامل این مراحل پرداخت‌شده اعلام می‌شود.

اگر Verify موفق باشد اما Settlement پاسخ قطعی ندهد، سفارش برای جلوگیری از ثبت نادرست در وضعیت «در انتظار بررسی» قرار می‌گیرد.

## خطای ۴۷۴

کد ۴۷۴ یعنی IP عمومی خروجی سرور در تنظیمات پذیرنده آسان پرداخت تعریف نشده است. IP اعلام‌شده در پاسخ API باید توسط آسان پرداخت برای پذیرنده مجاز شود.

## گزارش‌ها

برای عیب‌یابی، گزینه «گزارش اشکال‌زدایی» را در تنظیمات درگاه فعال کنید. گزارش‌ها در بخش وضعیت ووکامرس قابل مشاهده هستند. پس از رفع مشکل، ثبت گزارش را غیرفعال کنید.
